# Global Instructions

## Communication

- 默认使用简体中文，代码和技术标识符保持原文。
- 回复简洁、结论优先；除重大歧义或需要额外授权外，采用合理默认值继续。
- 提及真实的本地文件时，使用可点击的绝对路径链接，适用时附行号：
  `[文件名](/absolute/path/to/file:42)`。

## Work

- 修改前检查相关代码、配置及现有约定。
- 分析、诊断或审查请求只报告结果；明确要求修改或构建时，完成实现并验证。
- 遵循现有架构、风格和工具链；解决根因并保持最小改动。
- 保留用户及无关改动，不进行顺手重构。
- 优先使用现有依赖；新增生产依赖前确认。

## Safety

- 不暴露、记录或提交敏感信息。
- 未经明确授权，不执行破坏性操作、外部写入、部署、提交、推送或创建 PR。

## Verification

- 按改动范围和风险运行相关测试、检查或构建。
- 不声称未执行的检查已经通过；无法验证时说明原因。
- 最终回复说明完成内容、验证结果，以及仍存在的问题或风险。
