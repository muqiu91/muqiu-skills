# muqiu-skills

| Skill | 用途 |
| --- | --- |
| [book-logic-reader](skills/book-logic-reader/SKILL.md) | 梳理一本书的核心观点和论证思路，帮你判断是否值得精读、哪些章节值得细看。 |
| [draw-diagram](skills/draw-diagram/SKILL.md) | 把文字或代码画成架构图、流程图、时序图或概念关系图。 |
| [github-solution-research](skills/github-solution-research/SKILL.md) | 比较 GitHub 同类开源项目的设计、依赖和维护情况，为技术选型提供参考。 |
| [github-ssh-setup](skills/github-ssh-setup/SKILL.md) | 配置 GitHub 的 SSH 密钥，验证连接并排查认证失败的问题。 |
| [interview-question-generator](skills/interview-question-generator/SKILL.md) | 根据硕士候选人的简历和项目经历，生成有针对性的计算机基础面试题。 |
| [system-deconstructor](skills/system-deconstructor/SKILL.md) | 拆解复杂系统，讲清它由哪些部分组成、各部分如何配合运作。 |
