# 图表模板参考

## HTML模板结构

所有图表应使用以下基本HTML结构：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>图表标题</title>
    <style>
        /* CSS样式 */
    </style>
</head>
<body>
    <svg width="100%" height="100%" viewBox="0 0 1200 800">
        <!-- SVG内容 -->
    </svg>
</body>
</html>
```

## 架构图模板

### 分层架构图
- 展示：前端层、应用层、数据层
- 布局：垂直分层
- 连接：层间箭头表示调用关系

### 微服务架构图
- 展示：多个服务及其通信
- 布局：服务网格布局
- 连接：服务间API调用

## 流程图模板

### 业务流程图
- 元素：开始→步骤→决策→结束
- 布局：从上到下
- 分支：使用菱形决策节点

### 系统流程图
- 元素：输入→处理→输出
- 布局：从左到右
- 连接：数据流箭头

## 时序图模板

### 交互时序图
- 元素：对象生命线、消息、激活框
- 布局：水平时间轴
- 消息：同步/异步消息区分

## 组件图模板

### 组件依赖图
- 元素：组件框、接口、依赖箭头
- 布局：组件中心布局
- 分组：按功能模块分组

## 框架图模板

### 技术栈图
- 元素：技术层、技术标签
- 布局：垂直堆叠
- 颜色：不同层使用不同颜色

## 规划图模板

### 项目路线图
- 元素：时间轴、里程碑、任务
- 布局：水平时间轴
- 分组：按阶段或团队分组
