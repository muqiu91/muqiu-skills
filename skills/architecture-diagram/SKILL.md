# 架构图生成技能

## 概述

本技能帮助架构师根据用户提供的内容和需求，生成专业的设计图表。支持多种图表类型：架构图、流程图、组件图、时序图、框架图、规划图等。生成的图表以HTML格式输出，可转换为PNG图片。

## 工作流程

### 1. 理解用户需求

分析用户提供的内容和需求：
- **内容来源**：markdown文档、网页内容、纯文本、代码等
- **需求类型**：需要生成什么类型的图表（架构图、流程图等）
- **关键信息**：提取系统组件、流程步骤、关系、层次结构等
- **目标受众**：图表的使用场景和受众

### 2. 抽象和总结

从原始内容中提取关键要素：
- **实体识别**：识别系统组件、服务、模块、数据存储等
- **关系识别**：识别组件间的依赖、调用、数据流等关系
- **层次结构**：识别系统的分层架构、模块分组等
- **流程步骤**：识别业务流程、系统流程的步骤和决策点

### 3. 选择图表类型

根据需求选择合适的图表类型：

- **架构图**：展示系统整体架构、组件关系、技术栈
- **流程图**：展示业务流程、决策流程、系统流程
- **组件图**：展示系统组件及其依赖关系
- **时序图**：展示对象间的交互顺序和时间关系
- **框架图**：展示技术栈、框架层次、技术选型
- **规划图**：展示项目规划、路线图、里程碑

### 4. 设计图表

遵循专业设计原则（详见 `references/design_guidelines.md`）：

- **简洁性**：避免信息过载，聚焦核心内容
- **清晰性**：使用明确的标签和视觉层次
- **颜色搭配**：使用协调的配色方案，确保可读性
- **布局合理**：根据图表类型选择最佳布局方式
- **准确性**：必须保证各层级元素展示正确，不要出现子元素超出父元素展示，布局错乱等影响正常展示的情况


### 5. 生成HTML图表

使用HTML+SVG生成图表：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>图表标题</title>
    <style>
        /* 使用CSS变量管理颜色主题 */
        :root {
            --primary-color: #2563EB;
            --secondary-color: #3B82F6;
            --accent-color: #10B981;
            --text-color: #1F2937;
            --bg-color: #FFFFFF;
        }
        
        body {
            margin: 0;
            padding: 20px;
            font-family: 'Inter', 'PingFang SC', sans-serif;
            background: var(--bg-color);
        }
        
        svg {
            display: block;
            margin: 0 auto;
        }
    </style>
</head>
<body>
    <svg width="1200" height="800" viewBox="0 0 1200 800">
        <!-- SVG图表内容 -->
    </svg>
</body>
</html>
```

**关键要点**：
- 使用SVG进行矢量图形绘制，确保清晰度
- 使用CSS变量管理颜色，便于主题切换
- 设置合适的viewBox，支持缩放
- 添加适当的边距和间距

### 6. 转换为PNG（可选）

如果用户需要PNG格式，使用 `scripts/html_to_png.py` 脚本：

```bash
python3 scripts/html_to_png.py diagram.html output.png --width 1920 --height 1080
```

**参数说明**：
- `input.html`：输入的HTML文件
- `output.png`：输出的PNG文件（可选，默认为同名.png）
- `--width`：图片宽度（默认1920）
- `--height`：图片高度（默认1080）
- `--wait`：等待页面加载时间（秒，默认2）

**注意事项**：
- 需要安装Chrome浏览器和ChromeDriver
- 确保HTML文件可以在浏览器中正常渲染
- 对于包含动画的图表，适当增加wait时间

## 设计指南

### 颜色方案

根据图表类型选择合适的配色方案（详见 `references/design_guidelines.md`）：

- **架构图**：专业蓝色系（#2563EB主色）
- **流程图**：现代紫色系（#7C3AED主色）
- **组件图**：商务绿色系（#059669主色）
- **规划图**：中性灰色系（#374151主色）

### 布局原则

- **架构图**：分层布局（前端→中间层→后端→数据库）
- **流程图**：线性布局（从上到下或从左到右）
- **组件图**：中心辐射布局
- **时序图**：水平时间轴+垂直对象轴

### 视觉元素

- **矩形框**：使用圆角（rx=8），添加阴影效果
- **箭头**：使用SVG marker定义箭头样式
- **文字**：选择合适的字体大小（14-16px），确保可读性
- **间距**：保持元素间合理间距（至少20px）

**步骤**：

## 最佳实践

1. **理解优先**：充分理解用户需求和内容，确保图表准确反映系统/流程
2. **简洁明了**：避免信息过载，聚焦核心内容
3. **一致性**：保持视觉风格一致，使用统一的颜色和样式
4. **可读性**：确保文字清晰、颜色对比度足够
5. **可扩展性**：使用SVG和CSS变量，便于后续修改和扩展
